# Git & Vercel Auto-Deploy Rule

Sempre que concluir alterações, correções ou novas features validadas:
1. Faça o commit de todas as alterações relevantes com uma mensagem descritiva em Conventional Commits.
2. Faça o `git push origin main` para atualizar o repositório remoto e acionar automaticamente o deploy na Vercel para que o usuário possa testar diretamente na versão publicada.
